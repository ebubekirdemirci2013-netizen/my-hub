# my-hub

Roblox Script Hub mit vielen Funktionen und einer grafischen Benutzeroberfläche (GUI).

## 🚀 Loadstring (empfohlen)

Füge diese eine Zeile in einen **LocalScript** oder direkt in die **Exploit-Konsole** ein:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ebubekirdemirci2013-netizen/my-hub/d2c7036b65751566deed143fc430c8daad7a9d56/MyHub.lua", true))()
```

> Das Script wird automatisch von GitHub geladen – du musst nichts manuell kopieren.  
> Die vollständige Loader-Datei findest du in [`loader.lua`](loader.lua).

## MyHub.lua – Roblox Hub

**Manuell einfügen:** LocalScript → `StarterPlayerScripts`

### Funktionen

| Kategorie | Feature |
|---|---|
| 🏃 Bewegung | Speed Hack (×3), High Jump (×4), Fliegen (WASD + Space/Ctrl), NoClip |
| 👤 Spieler | HP auffüllen, Teleport zur Spawn, Spieler-Liste (Konsole) |
| 👁 Visuals | ESP (Spieler hervorheben), Vollmond-Lighting, Regenbogen-Ambient |
| 🌍 Welt | Baseplate entfernen, Schwerkraft halbieren / zurücksetzen |

### Hotkeys

| Taste | Aktion |
|---|---|
| **RightAlt** | Hub ein-/ausblenden |
| **W/A/S/D + Space/LCtrl** | Steuerung während Fliegen |

### Hinweis
Dieses Script ist ausschließlich für eigene private Roblox-Server / Studio-Tests gedacht.
