# My Hub ⚡

A professional Roblox executor utility hub with a clean GUI, six built-in tools, toast notifications, and a full activity log.

## Loader

Paste this **one line** into any executor and run it:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ebubekirdemirci2013-netizen/my-hub/main/hub.lua"))()
```

## Features

| Tab | Tools |
|---|---|
| 🏠 Home | Player info, game info |
| 🔢 Calculator | Expression evaluator, memory slots, history |
| 📝 Text Tools | Case convert, reverse, trim, ROT-13, Base64, word count |
| { } JSON | Parse, pretty-print, minify, key/value search |
| ⚙ Settings | Transparency slider, notifications toggle, reset position |
| 📋 Logs | Timestamped activity log, copy to clipboard |

See [`docs/DOCUMENTATION.md`](docs/DOCUMENTATION.md) for the full user guide.
